# 🍳 Cooking Tracker

A lightweight web app to track what you cook daily. Add dishes, select meal types (breakfast, lunch, dinner), and view your meals on a calendar with pictures.

## Features

- ✅ Add custom dishes with photos
- ✅ Pre-selected dish list for quick entry
- ✅ Select meal type (breakfast, lunch, dinner, snack, dessert)
- ✅ Calendar view with month/week navigation
- ✅ SQLite database (lightweight, file-based)
- ✅ Modern dark-mode UI with smooth animations
- ✅ Responsive design

## Tech Stack

- **Framework:** Next.js 14
- **Database:** SQLite (via Bun)
- **Styling:** CSS with CSS variables
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

This app is configured to auto-deploy to Vercel on every push to `main`.
